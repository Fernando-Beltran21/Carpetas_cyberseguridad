✅ The API key is no longer in this page or in app.js. The browser calls /api/secure-data on the same origin; nginx proxies that to the configured API and attaches the real X-API-Key header itself, from a value it reads out of its own container environment. The key never ships to the browser, so "View Source" or a curl+grep against these files finds nothing.
